# Kyverno CLI Installation Lab

Welcome to your first mission, astronaut. The Kyverno controller is already running in this training solar system, but you have no scanner in your hand yet. Your job is to install the standalone `kyverno` command-line tool, pinned to version `v1.13.2`, and prove that your shell runs exactly that version.

## Launching the Lab

Run this command to start the cluster:

```bash
astrona run --git ssh://git@github.com/astrona-io/ATS009.git -c sections/section-010/module-01/labs/lab-01
```

When you think you have finished, send it for grading:

```bash
astrona submit -c sections/section-010/module-01/labs/lab-01
```

When you are done, remove the lab:

```bash
astrona destroy ats-009-lab-001
```
