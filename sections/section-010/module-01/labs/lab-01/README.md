# Kyverno CLI Installation Sandbox

Welcome to the Module 1 targeted practice sandbox. In this lab, you will download, install, and verify the standalone `kyverno` CLI binary on a machine where the Kyverno controller is already running in-cluster.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS009.git -c sections/section-010/module-01/labs/lab-01
```
