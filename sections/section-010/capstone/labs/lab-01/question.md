# Question

Solve this question on: `terminal`

The kind cluster in this lab already has the Kyverno controller (`v1.13.2`) installed and running. The `kyverno` CLI is not installed.

1.  Install the Kyverno CLI, pinned exactly to `v1.13.2`, Linux `x86_64`, from the official GitHub release tarball.
2.  Confirm `kyverno version` reports `v1.13.2`.
3.  Generate a bash completion script for `kyverno` and place it at `/etc/bash_completion.d/kyverno`.
