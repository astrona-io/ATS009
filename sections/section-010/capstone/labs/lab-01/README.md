# Kyverno CLI Installation Capstone

Welcome to the Section 010 Capstone Challenge. In this lab, you will install a pinned Kyverno CLI version, verify its integrity against the official release artifact, and enable shell completion — connecting everything from both course parts into one end-to-end task.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS009.git -c sections/section-010/capstone/labs/lab-01
```
